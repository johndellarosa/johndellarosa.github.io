Definition

Enter observations as x, y, z, weight (the fourth value is optional and defaults to 1). Weights change the weighted mean, covariance, and principal axes. Marker size and opacity indicate relative observation weight. Drag to rotate and scroll to zoom.

Drag: rotate · Scroll: zoom · Double-click: reset view
Data pointsPC1PC2PC3Unweighted PC1 (optional)
Exponent applied to each supplied weight. 0 = equal weights, 1 = original weights, 2 = stronger emphasis.
Method: Nonnegative observation weights are normalized to sum to one. The mean is μ = Σwᵢxᵢ, and weighted covariance is S = Σwᵢ(xᵢ − μ)(xᵢ − μ)ᵀ. This is a probability-weighted covariance (no sample degrees-of-freedom correction). Optional standardization uses weighted variances. Arrows represent ±2.2 weighted standard deviations in PCA directions; signs are arbitrary. Zero weights exclude rows from the fitted PCA but not from the scatterplot. The unweighted comparison uses equal row weights. All coordinates shown are in the weighted-centered coordinate system, including when the unweighted PC1 is compared.
